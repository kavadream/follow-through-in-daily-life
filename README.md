## 读者反馈

欢迎在本项目的Issues中指出错字、论证缺口、来源问题，以及具体哪一处建议难以使用。请注明章节和段落，并尽量提供可核验的理由。讨论个人情境时，请勿提交自己或他人的敏感资料。

也欢迎提出翻译意见和候选修订，是否采纳由维护者审核。完整英文翻译现以预览版提供。后续修订应保留情境原有文化背景、事实限定和研究边界，不把中文虚构故事改成真实海外经历。

本书受习惯与自我调节相关写作启发，按独立问题结构创作，不是《掌控习惯》的翻译、缩写或改编。来源卡说明实际核读范围，不将摘要阅读称为论文全文研读。
